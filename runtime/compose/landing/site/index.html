Keep the same bookmark

Public DNS sends remote visitors to the edge VPS, which carries the request to the homelab through the encrypted NetBird tunnel.

Public DNS→edge VPS→NetBird→Homelab
100.64.0.10 · encrypted remote path

The hostname and TLS certificate stay the same; only the DNS answer changes.

Home Assistant is available only on the home LAN or through NetBird. Other administration tools remain private and are not listed here.
